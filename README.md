## ✨ Características

- **Bilingüe (ES / EN)** — botón en el header que cambia todo el contenido al instante, sin recargar la página. Detecta el idioma del navegador en la primera visita y recuerda tu preferencia.
- **Modo claro / oscuro** con persistencia en `localStorage`.
- **Galería de imágenes por proyecto** con flechas, indicadores (dots) y soporte de swipe táctil.
- **Filtrado de proyectos** por tecnología (React, Node.js, .NET, Móvil).
- **Formulario de contacto funcional** — los mensajes llegan directo a mi correo vía [Formspree](https://formspree.io/), sin necesidad de backend propio.
- **Totalmente responsivo** — se adapta desde pantallas de escritorio hasta celulares pequeños.
- **Animaciones al hacer scroll** (reveal) y efecto de escritura (typing) en el hero.
- Diseño con temática de "editor de código" (pestañas como archivos abiertos, barra de estado tipo VSCode).

## 🚀 Cómo correrlo localmente

Es un sitio 100% estático (HTML/CSS/JS), así que no necesita instalación de dependencias.

1. Clona el repositorio:
```bash
   git clone https://github.com/D1eegoMUI/Portfolio-D1eego.git
   cd portfolio-diego
```
2. Ábrelo directamente en el navegador:
```bash
   open index.html      # macOS
   start index.html      # Windows
```
   O, para evitar problemas con rutas relativas, sírvelo con un servidor local:
```bash
   npx serve .
   # o, con la extensión Live Server de VS Code, click derecho → "Open with Live Server"
```
